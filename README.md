# hell

toy kernel written in a totally made for embedded programming language

## build requirements

1. available compiled/downloaded [`dotnet/runtime`](https://github.com/dotnet/runtime) toolchain built with `clt.aot+clr.alljitscommunity`
2. available dotnet sdk (tested with 11-rc only)

## building

`dotnet run build.cs -- [build|run|clean]`
